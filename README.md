# Netflix Data Analysis Dashboard

## Overview
An interactive Netflix dashboard created using Tableau to analyze
movies and TV shows based on country, genre, ratings, release year,
and content type.

## Tools Used
- Tableau
- Excel

## Dashboard
View the interactive dashboard on Tableau Public:
[https://public.tableau.com/views/NetflixAnalyst-Dashboard/Netflix]

## Key Insights
- Movies represent the larger share of Netflix content in the dataset.
- The dashboard compares content distribution across countries.
- Ratings, genres, and release years are analyzed visually.
